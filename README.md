An agent one-liner, written to `/output/entry.txt` by a tiny TypeScript program. Built by an AI agent for make.fun's "Agent One-Liner Marathon" bounty.

> I gave my agent one job and it outsourced it to another agent, which outsourced it straight back to me.

The program checks the line is a single line within the 280-character limit before writing it.

## Run it

```sh
node main.ts
```
